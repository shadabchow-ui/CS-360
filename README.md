## App Summary
The app I developed is **Inventory Tracker**, a lightweight mobile inventory application designed to help users manage stock from a phone. It was built to address the needs of small businesses, warehouse staff, and independent sellers who need a simple way to log in securely, add items, update quantities, delete inventory, and receive optional alerts when stock reaches zero.

## User Needs and UI Design
To support user needs, the app included a login screen, an inventory display screen, item add/edit functionality, delete capability, and optional SMS alerts for zero inventory. My UI design focused on clarity, ease of navigation, and a simple layout so users could quickly complete inventory tasks without confusion. The design was successful because it kept the main tasks straightforward and avoided unnecessary complexity.

## Coding Approach
My coding approach was to break the app into smaller parts and build them step by step. I connected the user interface, SQLite database, login logic, CRUD features, and optional SMS functionality in stages so I could test each part as I went. This strategy helped me stay organized, troubleshoot more effectively, and understand how different parts of the app worked together. I can apply this same approach in future projects by continuing to build incrementally and focus on clean structure.

## Testing and Functionality
I tested the app by checking login behavior, database persistence, add/edit/delete inventory functions, and SMS permission handling. This process was important because it helped confirm that the code worked as intended and revealed issues that needed debugging, especially when different app features interacted with each other. Testing showed me that even small apps need careful checking to make sure the experience is reliable for the user.

## Innovation and Problem Solving
One challenge in the project was making sure the different app components worked together correctly while keeping the app simple for users. I had to think carefully about how to connect the interface, database operations, and permissions in a way that felt smooth and practical. This pushed me to be more organized and more thoughtful in both design and development.

## Strongest Area
The component where I was most successful in demonstrating my knowledge, skills, and experience was the overall integration of the app’s main features. I was able to combine login functionality, inventory management, persistent local storage, and optional alerts into one working application. This showed my growth in both technical development and user-centered design.
